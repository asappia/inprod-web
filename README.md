# In Prod. website

Show site for [In Prod.](https://www.inprod.fm), a weekday podcast. Subscribe at [media.inprod.fm/podcast.xml](https://media.inprod.fm/podcast.xml).

```bash
npm install
npm run dev
```

Deploy on Vercel. The podcast pipeline lives in [asappia/inprod](https://github.com/asappia/inprod).
